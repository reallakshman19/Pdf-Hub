=====================================

Objective:
Create schema contract, builder-state helpers, built-in recipe catalog, and recipe storage core.

Files:

Define MacroFieldType, MacroOpFieldSchema, MacroOpSchema.

- select_pages

- description
- fields
- defaultStep()

Utility exports:
- MACRO_OP_SCHEMAS
- OP_SCHEMA_BY_OP
- getMacroOpSchema(op)
- getMacroOpsByCategory()
