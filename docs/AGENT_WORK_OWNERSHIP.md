# Agent Work Ownership

This document assigns ownership of the main DocCraft modules to specific agents.  Clear delineation of responsibilities reduces merge conflicts and ensures that work streams can proceed in parallel without interfering with one another.  Agents should avoid modifying code owned by others without coordination.

| Agent | Scope | Key Files/Directories |
|-------|-------|----------------------|
| **00 – Contract Owner** | Defines and maintains the command contract, operation lifecycle and top‑level documentation.  Ensures that every new tool maps to a command. | `docs/IMPLEMENTATION_PLAN_REDESIGN.md`, `docs/OPERATION_CONTRACT.md`, `docs/AGENT_WORK_OWNERSHIP.md`, `frontend/src/core/commands/*` |
| **01 – Shell and Mode UX** | Builds the structural shell of the workbench (top bar, mode tabs, toolbar band, rails, panels).  Implements the editor state store to track the current mode.  Ensures that unimplemented tools are disabled and honestly labelled. | `frontend/src/components/shell/*`, `frontend/src/core/editor/*` |
| **02 – Viewer & Performance** | Implements the PDF renderer adapter and virtualised viewer.  Manages page metrics, caching, rendering cancellation and text layer optimisation. | `frontend/src/adapters/pdf-renderer/*`, `frontend/src/components/viewer/*` |
| **03 – Write Overlay** | Implements overlay writing tools: text boxes, images, table overlays and links.  Handles serialization and flattening of overlays. | `frontend/src/core/writer/*`, `frontend/src/components/writer/*`, `frontend/src/core/document/commitPipeline.ts` |
| **04 – Organize & Thumbnails** | Implements page organisation features and thumbnail panel (multi‑select, drag/drop, badges).  Connects to back‑end writer functions. | `frontend/src/core/pages/*`, `frontend/src/components/sidebar/ThumbnailPanel.tsx`, `frontend/src/components/pages/*`, `backend/pdf_engine/writer.py`, `backend/services/pdf_service.py` |
| **05 – OCR Workflow** | Implements asynchronous OCR, region classification, equation recognition and progress panels.  Manages state of OCR jobs and integrates with back‑end tasks. | `frontend/src/core/ocr/*`, `frontend/src/components/ocr/*`, `backend/services/ocr_service.py`, `backend/tasks/ocr_task.py` |
| **06 – Inspector, Search & Bookmarks** | Implements the inspector panel tabs, search engine and bookmark management.  Ensures that selections update inspector data and that search covers native text, OCR text, annotations and bookmarks. | `frontend/src/components/inspector/*`, `frontend/src/core/search/*`, `frontend/src/components/sidebar/SearchPanel.tsx`, `frontend/src/core/bookmarks/*`, `frontend/src/components/sidebar/BookmarksPanel.tsx` |
| **07 – Generate/Macro Guardrails** | Implements macro builder, AI suggestions and diff preview.  Validates AI‑generated commands and ensures user confirmation before applying. | `frontend/src/core/generate/*`, `frontend/src/components/generate/*`, `frontend/src/core/macro/*`, `backend/services/macro_service.py`, `backend/tasks/macro_task.py` |
| **08 – Redaction** | Implements redaction preview and apply logic.  Writes the back‑end redaction code to remove content destructively.  Ensures that OCR and native text under redaction are removed. | `frontend/src/core/redaction/*`, `frontend/src/components/redaction/*`, `backend/pdf_engine/redaction.py`, `backend/services/redaction_service.py`, `backend/app/api/redaction.py` |
| **09 – QA & Benchmark** | Writes unit, integration and e2e tests.  Maintains performance benchmarks and verification scripts. | `tests/e2e/*`, `tests/benchmark/*`, `docs/VERIFICATION_SYSTEM.md`, `docs/PERFORMANCE_BENCHMARKS.md` |

Agents must coordinate when their work crosses module boundaries.  For example, a new annotation tool requires collaboration between Agents 00 (command definition), 01 (toolbar integration), 02 (viewer overlays) and 03 (write overlay vs annotation distinction).  Agents should update this document when ownership boundaries change.
